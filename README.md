# 아브라칼큘러스! — v1.12.0 (PC·스마트폰 가로 화면)

미분하고, 적분하고, 살아남아라.

[게임 플레이](https://sy-harabi.github.io/math-mage/) · [소스코드](https://github.com/sy-harabi/math-mage)

PC에서는 WASD·방향키 또는 마우스 클릭으로, 스마트폰 가로 화면에서는 왼쪽 조이스틱으로 이동하며 미분·부정적분 문제를 풀어 마법을 사용하는 액션 RPG. 보스를 처치하면 스피드런 기록이 확정됩니다.

## 마법진 조작
- `1`: 번개 시전 (항별 도함수 조합 → 적 클릭). `2`: 파이어볼 시전 (항별 부정적분 조합 → 위치 클릭 즉시 폭발). `3`: 보호막 시전 (항별 미분 조합 → 즉시 보호막 충전). `4`: 힐 시전 (항별 부정적분과 +C 조합 → 즉시 회복).
- 문제는 반투명 오각형 마법진의 중앙에 표시되고, 다섯 꼭짓점에서 클릭 또는 터치로 답을 고릅니다. 답은 키보드 `1`~`5`로도 선택할 수 있습니다.
- **문제를 푸는 중에도** WASD·방향키 이동이 가능하며, 마법진의 빈 영역을 통과한 캔버스 클릭도 이동 명령으로 처리됩니다. `Esc`: 주문 취소.
- 분수와 지수는 브라우저 기본 MathML로 표시합니다. 3항까지 지원하며 항이 늘어날수록 글자를 줄입니다. PC 조작은 유지하며, 스마트폰 가로 화면에서는 오른쪽에 2×2 스킬 버튼을 표시합니다. 터치로 적 또는 공격 위치를 지정하고, 답은 기존 오각형에서 터치합니다. 스마트폰 세로 화면에서는 회전 안내를 띄우고 타이머와 전투를 일시정지합니다.
- 버프가 없으면 문제 중에도 세계 속도 100%, 시간 왜곡 업그레이드 1회당 15%p 감소 (최대 4회). 타게팅은 항상 정상 속도.

## 성장과 스피드런
- 번개 Lv1/Lv2/Lv3: 최대 1/3/5마리 연쇄 타격, 대상마다 각각 20/30/40 피해. 연쇄 거리 260px, 쿨타임 2/5/8초, 수학 문제는 1/2/3항. 각 항을 맞힐 때마다 오각형의 단항식 후보 5개를 새로 생성·배치합니다. 현재 항은 금빛으로 강조되며, 왼쪽 항부터 미분한 결과를 선택하면 중앙에 도함수가 쌓이고 충전 표시가 채워집니다. 안내 문구와 네모 빈칸은 표시하지 않으며, 한 번 틀리면 즉시 시전 실패입니다. 상수항은 미분 후 사라져 선택 횟수에서 제외하며, 상수함수는 0을 한 번 선택합니다.
- 힐 Lv1/Lv2/Lv3: 20 / 50 / 80 HP 회복. 파이어볼과 완전히 같은 1/2/3항 부정적분을 풀고 마지막 +C까지 선택해야 회복합니다. 매 답마다 보기 5개를 새로 배치합니다. 기본 쿨타임은 6초입니다.
- 파이어볼 Lv1/Lv2/Lv3: 10 / 30 / 70 피해, 부정적분 다항식 1 / 2 / 3항. 왼쪽부터 강조된 항의 원시함수를 선택해 전체 부정적분을 조합합니다. 각 항을 맞힐 때마다 보기 5개를 새로 생성·배치하며, 상수항도 ax로 적분해 선택합니다. 마지막에는 적분상수 +C를 직접 선택해야 시전됩니다. Lv1/2/3은 각각 2/3/4회 선택합니다. 오답 즉시 실패·되돌리기 없음. 분수 계수는 MathML로 표시합니다. 반지름 42px 고정·레벨별 쿨타임 5/8/10초. 조준 원 및 맞을 적을 미리 표시하고, 클릭 즉시 그 위치에 피해·처치·XP를 반영합니다.
- 보호막 Lv1/Lv2/Lv3: 번개와 같은 1/2/3항 미분 조합으로 매번 1/2/3회를 추가하고, 총 보유량은 최대 5회입니다. 기본 쿨타임 5/8/10초. 모든 피해를 한 번 막을 때 보호막 하나만 소모하고 정상 피격과 같은 0.65초 무적을 줍니다. 마지막 보호막도 HP 손실 없이 막습니다. 청록색 구체와 남은 횟수만큼의 방패 표식으로 표시하며, 파괴 시 섬광·파편과 캐릭터 점멸을 보여줍니다.
- 패시브 1회당 기동력은 기본 이동속도 +5%p, 생명력은 최대 HP +25 및 HP 25 회복, 집중은 모든 마법의 쿨타임 −1초입니다. 집중은 진행 중인 쿨타임도 1초 줄이며, 최소 0초까지 적용됩니다. 기존 강화 횟수 상한은 유지합니다.
- 수식 오답 후보의 기본 유형 가중치: 공식 적용 50%, 부호·적분상수 20%, 단순 계산 30%. 같은 뜻의 선택지는 제거합니다.
- 일반 적 처치로 XP 획득, 레벨업 시 스킬 강화·기동력·생명력·집중·시간 왜곡 중 3개 제안. 패시브가 남아 있으면 스킬 강화는 최대 두 종류와 패시브 하나를 제안합니다.
- 보이지 않는 내부 난이도는 총 7단계입니다. 생성 간격은 1~4단계 4/3.5/3/2.5초, 5~7단계 2초입니다. 기본/빠른/원거리/바위 비율은 1단계 80/20/0/0%, 2단계 65/35/0/0%, 3단계 45/35/20/0%, 4단계 35/40/25/0%, 5단계 25/35/25/15%, 6단계 20/30/25/25%, 7단계 20/30/30/20%입니다. 적 동시 개체 수 상한이 없으며 이전 몬스터는 유지됩니다. 보스는 7단계 시작 즉시 생성됩니다.
- 슬라임 군주 보스를 처치하면 완료 시간과 처치 수를 보여줍니다. 기록 시간은 스킬 습득·강화 선택 중과 비활성 탭에서 정지합니다. 주문 문제 풀이·조준 중에는 감속과 관계없이 실제 시간으로 측정합니다.
- `?debug=1`은 1~7단계 스테이지 선택 및 스킬 레벨 테스트 메뉴를 활성화합니다. 단계 선택 시 스킬·성장·XP를 유지하고 체력과 쿨타임을 회복하며 적·시전·기록을 초기화합니다. 7단계 선택 시 보스가 즉시 등장합니다.

## 개발
- 테스트: `npm test`; 정적 로컬 서버: `python -m http.server 8000`.
- `main` 브랜치에 커밋하면 GitHub Actions로 테스트 후 Pages에 배포됩니다.
- 서버 저장과 온라인 순위는 없습니다. 모바일은 가로 화면에서 터치로 플레이할 수 있으나, 기기별 실기기 검증은 별도로 필요합니다.

## v1.7.0 네온 디자인

- 짙은 남색 아레나, 청록색 마법사와 형태로 구별되는 네온 슬라임, 마법별 색상의 오각형 마법진을 적용했습니다. 수식은 MathML로 유지합니다.
- 체력·방어막·시간 HUD와 번개 / 화염구 / 방어막 / 힐 아이콘 슬롯, 하단 XP 표시를 정리했습니다.
- 원거리 슬라임은 외눈 렌즈와 집광 장치를 가진 레이저 슬라임입니다. 고정된 조준 방향으로 렌즈가 향하며 충전 링, 피해 폭과 일치하는 조준선, 보라색 빔으로 공격을 표시합니다. 공격 시간·범위·판정과 몬스터 능력치는 유지합니다.
- 캔버스 크기 변화에만 마법진 배율을 맞추며 시전 상태에 따라 화면 배율을 바꾸지 않습니다.


## v1.8 성장 밸런스
- 시작 스킬은 번개 Lv1뿐입니다. 화염구·방어막·힐은 미습득 상태로 표시되며 단축키도 비활성화됩니다.
- 미습득 스킬을 처음 선택하면 Lv1을 배우고, 이후 선택은 Lv2·Lv3 강화입니다. 습득 선택지에는 Lv1 효과를 표시합니다. 기존 3개 선택지 구성(스킬 2개 + 패시브 1개)을 유지합니다.
- 번개 기본 쿨타임은 Lv1/2/3 각각 2/5/8초입니다. 집중은 기존처럼 1회당 고정 1초를 줄이며 최솟값은 0초입니다.
- 다음 레벨에 필요한 XP는 12/18/24/30/36…으로, 누적 Lv2~6 기준 12/30/54/84/120입니다(이전 24/52/100/168/256). 첫 선택은 기본 슬라임 2마리 처치로 열립니다.

## v1.8.1 선택 카드
- 습득 카드는 Lv1 효과, 강화 카드는 현재 → 다음 레벨의 실제 수치를 행별로 표시합니다. 피해·대상 수·회복·충전·쿨타임·문제 항 수를 해당 레벨에서 계산합니다.
- 집중에 따른 실제 쿨타임과 누적 패시브 수치를 반영하고, 변하지 않는 수치는 유지로 표시합니다.
- 스킬 선택 중에는 전투와 기록이 모두 정지합니다. 문제 풀이와 조준은 기록에 포함합니다.

## v1.9.0 바위 슬라임과 7단계 전투

- 바위 슬라임은 5단계부터 출현합니다. 기본 체력 60, 속도 115px/s, 접촉 피해 20(간격 1.5초), XP 12, 단계 진행도 9입니다. 기존 6단계 강화로 체력 68, 접촉 피해 22, 착지 피해 26이 적용됩니다.
- 점프는 착지 후 4초 쿨타임, 120~500px 거리에서 시도하며 최대 420px를 700px/s로 이동합니다. 0.7초 예고 시작 순간 목표를 고정하고, 경고 원은 플레이어 반경까지 포함한 실제 판정을 표시합니다.
- 공중에서는 몬스터를 넘어가며 접촉 피해가 없고, 착지 순간 반경 65px에 기본 24 피해를 한 번 줍니다. 착지 후 0.6초 동안 멈춥니다. 점프 중에도 떠 있는 몸체를 클릭해 번개를 맞힐 수 있습니다.
- 보스 기본 이동속도는 160px/s입니다. 기존 돌진 900px/s와 공격 패턴을 유지하고, 7단계 시작 즉시 생성되며 처치 시 기록을 확정합니다.

## v1.10.0 결과 화면 캡처

- 보스 격파·사망 결과 화면에서 '캡처 저장 (PNG)'을 누르면 최종 전투 장면, 결과, 고정된 시간, 처치 수와 캐릭터 레벨을 이미지로 저장합니다.
- 사망 화면에도 생존 시간과 다시 도전 버튼을 표시하며, 격파·사망 후 기록은 계속 정지합니다.

## v1.11.0 미분·적분 시각 피드백

- 미분은 d/dx(원식), 적분은 ∫(원식)dx로 표시하며 아래 = 행에 답을 조합합니다. 현재 항은 12% 확대하고 처리한 항은 흐리게 표시합니다.
- 정답 룬이 조합된 항으로 0.23초 동안 이동하고, 완성된 식은 0.5초 동안 짧게 남습니다. 선택지 갱신·이동·마법 발동·쿨타임·기록에는 지연을 추가하지 않습니다.
- 새 주문·취소·재시작·사망·클리어 시 남은 연출을 정리하고, 동작 줄이기 설정에서는 이동 연출을 생략합니다.

## v1.12.2 개발자 화면 모드 강제 전환
- `?debug=1`로 접속하면 상단의 `개발자 · 화면 모드` 메뉴에서 자동 / 모바일 / PC를 즉시 전환할 수 있습니다.
- 스마트폰 인식이 실패하면 `?debug=1&ui=mobile`로 접속하여 모바일 화면을 강제로 적용할 수 있습니다.
- `?debug=1&ui=pc`는 PC 화면을 강제 적용하고, 자동으로 돌아가면 `ui` 파라미터가 제거됩니다.
- 이 디버그 설정은 게임의 문제·전투 규칙에 영향을 주지 않으며, URL에 반영되어 새로고침 후에도 유지됩니다.
