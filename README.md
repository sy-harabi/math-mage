# 계산 마법사 (Math Mage) — v1.0

**[브라우저에서 플레이](https://sy-harabi.github.io/math-mage/)** · [GitHub 저장소](https://github.com/sy-harabi/math-mage)

수학 문제를 풀어 주문을 사용하는 2D 서바이벌 액션 게임. 정답 선택 시에도 월드 시간은 75% 속도로 흐르고, 스킬 쿨타임은 실제 시간으로 흐릅니다.

## 플레이

- WASD/방향키 또는 마우스 클릭 이동. 이동키를 누르면 기존 마우스 자동 이동 목표가 취소됩니다.
- `1` 번개: 도함수 문제 정답 → 몬스터 클릭. Lv1 20, Lv2 30/15, Lv3 35/25/15 순차 연쇄 피해(연쇄 거리 260px).
- `2` 힐: 부정적분 문제 정답 → HP 회복. Lv1 +10, Lv2 +25, Lv3 +50.
- 스킬 레벨이 올라갈수록 1항 → 2항 → 3항의 미분/부정적분 문제를 풉니다.
- 각 문제는 정답 1개 + 오답 4개. 오답 유형 가중치는 공식 적용 실수 50%, 부호·적분상수 실수 20%, 단순 계산 실수 30%입니다. 분수 계수는 정확한 기약분수로 처리하며, 적분 정답에는 `+ C`가 붙습니다.
- 오답: 주문 취소 및 1.5초간 이동속도 50% 감소. 쿨타임은 기본적으로 번개 2초, 힐 6초입니다.

## 스테이지 (시간 + 처치)

- 스테이지 진행도는 **게임 시간 기준 초당 0.6%** 상승. 처치 보너스: 기본 슬라임 +6% / 빠른 슬라임 +7% / 원거리 슬라임 +8%.
- 스테이지 진행도 100%가 되면 2초간 전환 연출을 보인 뒤 다음 스테이지로 이동합니다. 이전 적과 투사체는 XP 없이 퇴장합니다.
- **5의 배수 스테이지:** 진행도 70%에서 보스 등장. 보스가 살아 있는 동안 진행도는 99%를 넘지 못하며, 처치하면 100%가 됩니다.
- 모든 스테이지에서 일반 몬스터는 **동시 개체 수 제한 없이** 일정 간격으로 생성됩니다. 화면 바깥을 우선해서 스폰합니다.
- 주문 시전 중에는 스테이지 시간과 몬스터 스폰도 75% 속도로 느려집니다. 업그레이드 선택과 스테이지 전환 중에는 전투가 완전히 일시정지됩니다.

| 스테이지 | 일반 몬스터 스폰 간격 | 적 구성 |
|---|---:|---|
| 1 | 10초 | 기본 100% |
| 2 | 8초 | 기본 70%, 빠른 30% |
| 3 | 7초 | 기본 50%, 빠른 25%, 원거리 25% |
| 4 | 6초 | 기본 40%, 빠른 35%, 원거리 25% |
| 5 | 12초 | 기본 45%, 빠른 30%, 원거리 25% + 70%에 보스 |
| 6~ | 점진적으로 단축 (최저 4초) | 혼합 적 + 매 5스테이지 보스 |

## 몬스터 스펙 (기본치)

| 적 | HP | 이동속도 (px/게임초) | 공격 피해 | 처치 XP |
|---|---:|---:|---:|---:|
| 기본 슬라임 | 40 | 54~79 | 12 (접촉) | 6 |
| 빠른 슬라임 | 25 | 135 | 8 (접촉) | 8 |
| 원거리 슬라임 | 30 | 55 | 10 (투사체) | 10 |
| 보스 (슬라임 군주) | 260 | 65 | 내려찍기 20 / 돌진 16 | 50 |

- 원거리 슬라임: 230~320px 거리 유지, 0.8초 조준선 예고, 투사체 속도 190px/s, 공격 간격 3.5초.
- 보스: 1.2초 예고 후 반경 130px 내려찍기, 0.9초 예고 후 0.7초 직선 돌진, 12초마다 기본 슬라임 1~2마리 소환. HP가 절반 미만이면 공격 주기가 짧아집니다.
- 스테이지 6부터 5스테이지마다 몬스터 기본 HP와 공격력이 조금 증가합니다.

## XP와 레벨업

XP는 몬스터 처치로만 획득합니다. 스테이지 게이지와 XP는 서로 독립적이며 스테이지 전환 후에도 획득 XP와 스킬 강화는 유지됩니다.

| 캐릭터 레벨 | 누적 필요 XP |
|---|---:|
| 2 | 24 |
| 3 | 52 |
| 4 | 100 |
| 5 | 168 |
| 6 | 256 |

레벨업하면 게임을 멈추고 **강화 선택지 3개 중 하나**를 고릅니다. 주문 시전 중 레벨업했다면 그 주문이 끝난 뒤 선택창이 열립니다. 연속 레벨업하면 선택창도 차례로 표시됩니다.

- **번개 강화:** 다음 레벨(최대 Lv3). 추가 항 미분, 연쇄 타격 증가.
- **힐 강화:** 다음 레벨(최대 Lv3). 추가 항 부정적분, 회복량 증가.
- **기동력:** 이동속도 +8% (최대 6회).
- **생명력:** 최대 HP +15 및 즉시 HP 15 회복 (최대 6회).
- **집중:** 모든 스킬 쿨타임 7% 감소 (최대 5회).
- **보호막 스킬은 구현하지 않았습니다.**

### 디버그 및 밸런싱

`?debug=1`을 게임 주소 끝에 추가하면 별도로 존재하는 번개/힐 Lv1~3 **체험 버튼**이 표시됩니다. 일반 플레이에서는 스킬 강화를 얻으려면 반드시 XP로 레벨업해야 합니다.

## 프로젝트 구조

```text
index.html                  화면, HUD, 업그레이드 모달
src/game.js                 입력, 전투, 몬스터 AI, 렌더링, 게임 흐름
src/styles.css              화면 스타일
src/spells.js               마법 레벨별 피해량·회복량·문제 설정
src/problem-engine.js       문제·오답 생성
src/monomial.js             유리수 계수 단항식
src/polynomial.js           다항식 정규화·출력
src/combat.js               번개 연쇄 타격 및 힐 계산
src/enemy-types.js          몬스터 기본 능력치
src/spawn-director.js       스테이지별 스폰 주기와 위치·종류 선택
src/stage-director.js       스테이지 진행도·보스 관문
src/progression.js          XP 요구량·누적 XP·레벨업 판정
src/upgrades.js             업그레이드 후보·효과·상한
.github/workflows/pages.yml 자동 테스트 및 Pages 배포
tests/*.test.mjs            Node.js 테스트
```

개발 서버: `python -m http.server 8000` → `http://localhost:8000/`. 테스트: `npm test`. `main` 브랜치에 커밋하면 자동으로 GitHub Pages 배포가 실행됩니다. 게임은 서버에 기록을 저장하지 않습니다.
