# 계산 마법사 (Math Mage) — v0.9

[게임 플레이 (GitHub Pages)](https://sy-harabi.github.io/math-mage/) · [소스 코드](https://github.com/sy-harabi/math-mage)

캐릭터를 중심으로 카메라가 이동하는 2D 수학 액션 RPG 프로토타입. 마법을 쓰려면 오각형 마법진에 표시된 문제의 정답을 선택해야 한다.

## 조작

- `WASD` / 방향키로 이동하거나 바닥을 클릭해서 자동 이동. 이동키를 누르면 자동 이동 목표가 취소된다.
- `1` 번개: 미분 문제 풀이 → 공격할 적 클릭 → 최대 1~3개체 순차 공격.
- `2` 힐: 부정적분 문제 풀이 → 자기 자신을 회복.
- 마법 시전 중 게임 속도 75%, 오답 시 시전 취소 및 1.5초 동안 이동속도 50% 감소.
- MP 없음. 번개 쿨타임 2초, 힐 쿨타임 6초. 쿨타임은 실제 시간 기준.
- 체력은 플레이어 머리 위의 초록색 막대, 번개 준비 상태는 번개 아이콘으로 표현.

## 스킬 레벨 (현재는 별도 체험 버튼으로 변경)

| 레벨 | 번개 문제 | 번개 연쇄 피해 (타격 순서대로) | 힐 문제 | 힐 회복량 |
|---|---|---|---|---|
| 1 | 1항 미분 | 20 | 1항 부정적분 | 10 |
| 2 | 2항 미분 | 30 → 15 | 2항 부정적분 | 25 |
| 3 | 3항 미분 | 35 → 25 → 15 | 3항 부정적분 | 50 |

번개 연쇄는 사용자가 클릭한 대상을 먼저 공격하고, 그 적으로부터 거리 260px 이내에 있는 아직 공격하지 않은 가장 가까운 적에게 이어진다. 범위 내 적이 없으면 남은 타격은 발생하지 않는다. 힐은 최대 HP 100을 초과하여 회복하지 않는다.

번개와 힐 레벨을 각각 독립적으로 선택할 수 있다. 시전 도중 레벨을 바꾸면 현재 시전에는 영향을 주지 않으며 다음 주문부터 반영된다. 게임 내 경험치·자동 성장·스테이지 시스템은 **아직 구현 전**이다.

## 문제 생성 규칙

- 번개: `f(x)`로 제시된 1~3항 다항식의 도함수를 구한다. 계수는 정수 `−5~−1, 1~5`, 차수는 `2~4`.
- 힐: `∫ f(x) dx`로 제시된 1~3항 다항식의 부정적분을 구한다. 계수는 정수 `−5~−1, 1~5`, 원래 함수의 차수는 `1~3`, **정답에 `+ C`가 포함**된다.
- 보기 5개는 정답 1개와 오답 4개. 오답 각각의 유형 가중치는 **공식 오류 50% / 부호·적분상수 오류 20% / 계산 오류 30%**.
- 오답의 수학적 동치 여부를 정수 분자·분모의 기약분수 표현으로 검사한다. 적분상수 누락은 확률적으로 등장하며 고정되지 않는다.
- 새로운 스킬 문제 및 각 레벨의 항 수·계수·차수는 [`src/spells.js`](src/spells.js)의 설정에서 바꾼다. [`src/problem-engine.js`](src/problem-engine.js)는 문제와 오답을, [`src/polynomial.js`](src/polynomial.js)는 다항식 표기를 관리한다.

## 프로젝트 구조

```text
index.html                     # 게임 시작 페이지
src/game.js                    # 이동·카메라·전투·마법 UI
src/spells.js                  # 스킬별 레벨 설정과 출제 규칙
src/monomial.js                # 단항식·기약분수 계산
src/polynomial.js              # 다항식 정규화·표시
src/problem-engine.js         # 문제 및 가중치 기반 오답 생성
src/combat.js                 # 연쇄 타격, 피해 순서, 회복량 계산
src/styles.css                # UI 디자인
tests/*.test.mjs              # 수학 문제와 전투 규칙 자동 검증
.github/workflows/pages.yml  # main 브랜치 GitHub Pages 자동 배포
```

## 개발

- Node.js로 `npm test` 실행 (외부 패키지 설치 불필요).
- 로컬 개발 서버는 `python -m http.server 8000` 후 `http://localhost:8000/` 접속.
- ES 모듈을 사용하므로 일반적인 `file://` 직접 열기는 권장하지 않는다.
- `main` 브랜치에 커밋하면 GitHub Actions가 테스트 후 정적 파일을 배포한다.

현재 등장하는 적은 기본 슬라임뿐이다. 빠른 슬라임, 원거리 슬라임, 보스, 스테이지, 보호막은 구현하지 않았다.
