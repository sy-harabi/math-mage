# 계산 마법사 (Math Mage) — v1.4.0 (PC 전용)

[게임 플레이](https://sy-harabi.github.io/math-mage/) · [소스코드](https://github.com/sy-harabi/math-mage)

PC 브라우저에서 WASD·방향키 또는 마우스 클릭으로 이동하며 미분·부정적분 문제를 풀어 마법을 사용하는 액션 RPG. 보스를 처치하면 스피드런 기록이 확정됩니다.

## 마법진 조작
- `1`: 번개 시전 (문제 정답 선택 → 적 클릭). `2`: 힐 시전 (문제 정답 선택 → 즉시 회복). `3`: 파이어볼 시전 (개념 문제 연속 정답 → 폭발 위치 클릭).
- 문제는 반투명 오각형 마법진의 중앙에 표시되고, 다섯 꼭짓점에서 마우스로 답을 고릅니다. 답은 키보드 `1`~`5`로도 선택할 수 있습니다.
- **문제를 푸는 중에도** WASD·방향키 이동이 가능하며, 마법진의 빈 영역을 통과한 캔버스 클릭도 이동 명령으로 처리됩니다. `Esc`: 주문 취소.
- 분수와 지수는 브라우저 기본 MathML로 표시합니다. 3항까지 지원하며 항이 늘어날수록 글자를 줄입니다. UI는 PC 화면 전용으로 구성했고 모바일·태블릿 터치 조작은 지원하지 않습니다.
- 버프가 없으면 문제 중에도 세계 속도 100%, 시간 왜곡 업그레이드 1회당 15%p 감소 (최대 4회). 타게팅은 항상 정상 속도.

## 성장과 스피드런
- 번개 Lv1/Lv2/Lv3: 최대 1/3/5마리 연쇄 타격, 대상마다 각각 20/30/40 피해. 연쇄 거리 260px, 수학 문제는 1/2/3항.
- 힐 Lv1/Lv2/Lv3: 20 / 50 / 80 HP 회복. 각 레벨의 수학 문제는 1/2/3항.
- 파이어볼 Lv1/Lv2/Lv3: 10 / 30 / 70 피해, 개념 문제 1 / 2 / 3개. 각 질문은 빈칸 한 개이며 보기 5개의 내용·위치는 시전 중 고정되고 재사용할 수 있습니다. 한 번 틀리면 즉시 실패하며 되돌리기가 없습니다. 반지름은 기본 슬라임 한 마리 너비인 42px로 고정, 적 충돌 원이 폭발 원과 닿으면 타격합니다. 투사체가 클릭한 위치에 도착할 때 피해를 주며, 기본 쿨타임은 4초입니다.
- 번개·힐 문제의 오답 유형 가중치: 공식 적용 50%, 부호·적분상수 20%, 단순 계산 30%. 같은 뜻의 선택지는 제거합니다.
- 일반 적 처치로 XP 획득, 레벨업 시 스킬 강화·기동력·생명력·집중·시간 왜곡 중 3개 제안. 보호막은 미구현.
- 보이지 않는 내부 난이도 단계에 따라 스폰 간격이 4→3.5→3→2.5→2초로 단축됩니다. 기본/빠른/원거리 슬라임 출현 비율은 1단계 80/20/0%, 2단계 65/35/0%, 3단계 45/35/20%, 4단계 35/40/25%, 5단계 30/40/30%입니다. 적 동시 개체 수 상한이 없으며 이전 몬스터는 유지됩니다.
- 슬라임 군주 보스를 처치하면 완료 시간과 처치 수를 보여줍니다. 게임 시간은 업그레이드 선택 중 및 비활성 탭에서 정지합니다.
- `?debug=1`은 스킬 레벨 테스트 메뉴를 활성화합니다.

## 개발
- 테스트: `npm test`; 정적 로컬 서버: `python -m http.server 8000`.
- `main` 브랜치에 커밋하면 GitHub Actions로 테스트 후 Pages에 배포됩니다.
- 서버 저장, 온라인 순위 및 모바일 최적화는 없습니다.

## v1.3.1 카메라 안정화

마법진을 여닫거나 정답을 선택해 타게팅으로 바뀔 때 카메라를 옆으로 옮기지 않습니다. 카메라 중심은 모든 상태에서 플레이어를 기준으로 계산하고 시야/확대 비율은 고정합니다.

## v1.3.2

마법진이 플레이어의 화면 위치를 따라 이동합니다. 삼항 문제·보기 수식은 각각 30% 확대했습니다(14→18.2px, 11→14.3px). 보기 폭도 220px로 조정했습니다.

## v1.3.3

몬스터끼리 작은 충돌 원을 기준으로 부드럽게 밀어내며, 보스는 일반 몬스터에 밀리지 않습니다. 번개 조준 중에는 커서가 가리키는 한 마리의 테두리·체력바·HP를 강조합니다. 강조 대상과 클릭 대상은 같은 선택 규칙을 사용합니다.

## v1.4.0 파이어볼과 개념 주문

- 연속, 중간값 정리, 평균변화율, 미분계수·도함수 정의, 미분 가능성과 연속, 롤의 정리, 평균값 정리, 극값의 필요조건, 증가·감소, 부정적분, 정적분의 12개 주제를 추가했습니다. 같은 정리에서도 빈칸 위치가 달라집니다.
- 전체 질문과 공통 보기 5개를 시전 시작 시 생성합니다. 동치인 식, 자명한 등식, 함께 정답이 되는 조건은 해당 빈칸의 오답 후보에서 제외합니다.
- 개념 문제는 기존 오각형 마법진 중앙에 표시되고, 질문이 바뀌어도 다섯 답 노드는 교체하지 않습니다. 문제 풀이 중 이동·카메라와 시간 왜곡 동작을 유지합니다.
- 파이어볼 강화와 디버그용 Lv1~3 선택을 추가했습니다. 일반 레벨업에서는 스킬 세 종류 중 최대 두 종류와 기존 패시브 강화 후보를 제시합니다.
