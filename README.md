# 계산 마법사 (Math Mage) — v1.3.2 (PC 전용)

[게임 플레이](https://sy-harabi.github.io/math-mage/) · [소스코드](https://github.com/sy-harabi/math-mage)

PC 브라우저에서 WASD·방향키 또는 마우스 클릭으로 이동하며 미분·부정적분 문제를 풀어 마법을 사용하는 액션 RPG. 보스를 처치하면 스피드런 기록이 확정됩니다.

## 마법진 조작
- `1`: 번개 시전 (문제 정답 선택 → 적 클릭). `2`: 힐 시전 (문제 정답 선택 → 즉시 회복).
- 문제는 반투명 오각형 마법진의 중앙에 표시되고, 다섯 꼭짓점에서 마우스로 답을 고릅니다. 답은 키보드 `1`~`5`로도 선택할 수 있습니다.
- **문제를 푸는 중에도** WASD·방향키 이동이 가능하며, 마법진의 빈 영역을 통과한 캔버스 클릭도 이동 명령으로 처리됩니다. `Esc`: 주문 취소.
- 분수와 지수는 브라우저 기본 MathML로 표시합니다. 3항까지 지원하며 항이 늘어날수록 글자를 줄입니다. UI는 PC 화면 전용으로 구성했고 모바일·태블릿 터치 조작은 지원하지 않습니다.
- 버프가 없으면 문제 중에도 세계 속도 100%, 시간 왜곡 업그레이드 1회당 15%p 감소 (최대 4회). 타게팅은 항상 정상 속도.

## 성장과 스피드런
- 번개 Lv1/Lv2/Lv3: 20 / 30·20 / 40·30·20의 순차 타격, 연쇄 거리 260px.
- 힐 Lv1/Lv2/Lv3: 20 / 50 / 80 HP 회복. 각 레벨의 수학 문제는 1/2/3항.
- 문제의 오답 유형 가중치: 공식 적용 50%, 부호·적분상수 20%, 단순 계산 30%. 같은 뜻의 선택지는 제거합니다.
- 일반 적 처치로 XP 획득, 레벨업 시 스킬 강화·기동력·생명력·집중·시간 왜곡 중 3개 제안. 보호막은 미구현.
- 보이지 않는 내부 난이도 단계에 따라 스폰 간격이 6→5→4→3→2초로 단축됩니다. 적 동시 개체 수 상한이 없으며 이전 몬스터는 유지됩니다.
- 슬라임 군주 보스를 처치하면 완료 시간과 처치 수를 보여줍니다. 게임 시간은 업그레이드 선택 중 및 비활성 탭에서 정지합니다.
- `?debug=1`은 스킬 레벨 테스트 메뉴를 활성화합니다.

## 개발
- 테스트: `npm test`; 정적 로컬 서버: `python -m http.server 8000`.
- `main` 브랜치에 커밋하면 GitHub Actions로 테스트 후 Pages에 배포됩니다.
- 서버 저장, 온라인 순위 및 모바일 최적화는 없습니다.

## v1.3.1 카메라 안정화

마법진을 여닫거나 정답을 선택해 타게팅으로 바뀔 때 카메라를 옆으로 옮기지 않습니다. 카메라 중심은 모든 상태에서 플레이어를 기준으로 계산하고 시야/확대 비율은 고정합니다.

## v1.3.2

마법진이 플레이어의 화면 위치를 따라 이동합니다. 삼항 문제·보기 수식은 각각 30% 확대했습니다(14→18.2px, 11→14.3px). 보기 폭도 220px로 조정했습니다.
